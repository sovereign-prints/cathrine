📞 SUPPORT & TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

ISSUE: Quote form won't submit
SOLUTION:
  1. Check browser console for errors
  2. Verify API endpoint: /api/quotes
  3. Check file size (max 10MB)
  4. Check internet connection

ISSUE: PDF won't generate
SOLUTION:
  1. Verify Puppeteer installed: npm install puppeteer
  2. First run may take 30 seconds (downloading browser)
  3. Check server logs for errors
  4. Verify quote/order exists in database
  5. Check available disk space (at least 1GB for Puppeteer)

ISSUE: Admin dashboard won't load
SOLUTION:
  1. Clear browser cache
  2. Verify admin login works
  3. Check network tab for failed requests
  4. Verify authentication cookie
  5. Try different browser
